农屿APP详细技术说明

微信开放平台应用信息 - 四川农业大学校园助手

应用概述

基本信息

  • 应用名称：农屿川农校园助手
  • 应用类型：校园服务类移动应用
  • 目标用户：四川农业大学在校学生、教职工
  • 用户规模：面向川农约3万余名师生
  • 开发框架：uni-app
  • 数据存储：本地SQLite数据库 + 云端数据同步

技术架构

uni-app Spring Boot MySQL Redis
  • 响应式布局，适配多种屏幕
  • 本地缓存机制，提升体验
  • RESTful API接口设计

核心功能详解

智能课表管理

教务网API同步：通过教务网API自动同步用户课表数据
离线查看：支持课表离线查看，无需重复登录
旷课统计：旷课次数统计与提醒功能
冲突检测：课程时间冲突检测
课表分享：课表分享功能

校园社区交流

食堂评分：食堂窗口评分系统（1-5星评价）
课程评价：课程评价与选课建议
校园论坛：校园论坛讨论功能
内容审核：内容审核机制，确保言论合规
身份验证：用户身份验证，仅限川农师生

教务信息查询

成绩查询：成绩查询与学分统计
专业排名：专业排名查看
通知推送：教务通知实时推送
网址导航：重要网址导航
考试安排：考试安排查询

竞赛信息发布

竞赛推送：校园竞赛信息推送
教学通知：教学通知及时获取
活动报名：活动报名功能
获奖展示：获奖信息展示

合规性说明

内容审核机制

审核流程

  • 用户发布内容需通过关键词过滤
  • 禁止发布侮辱性、攻击性言论
  • 客观评价食堂和课程，避免恶意攻击
  • 用户举报机制，及时处理违规内容
  • 管理员审核制度

用户身份验证

  • 仅限四川农业大学师生使用
  • 通过教务网账号验证身份
  • 防止校外人员恶意注册
  • 保护校园信息安全

数据保护

隐私保护

  • 严格遵守《网络安全法》

  • 定期数据安全审计

安全措施

  • 用户密码本地加密存储

  • 唯一设备登录机制
  • 数据传输加密
  • 用户隐私保护
